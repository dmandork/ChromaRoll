2. Game Overview
ChromaRoll combines Balatro-inspired progression with Yahtzee-style dice rolling. Players form hands to beat blind targets, equip charms for bonuses, select starting bags, face boss effects, and shop between rounds. Progression through stakes increases difficulty, with new tags allowing blind skips for buffs (at the cost of coins/shop access). Game ends after round 8 with endless mode option. 50+ charms are functional; total planned: 108, with many unlockable via achievements.
2.1 Key Mechanics

Dice and Hands: Roll 5 colored dice; hold/reroll/discards to form hands (e.g., Pair, Straight, Flush). Scores beat blinds.
Charms: 108 total (50+ implemented); effects like multipliers or modifiers. Half+ unlockable (e.g., "Play 100 Three of a Kind" or "Score >5k in one hand").
Bags (Pouches): Starting bonuses; unlockable via conditions (e.g., complete X stakes, achieve Y scores).
Boss Effects: 30+ modifiers; special variants for final boss (e.g., amplified effects, multi-phase challenges).
Blinds and Tags: Targets to beat; tags allow skipping small/large blinds for buffs (instant or delayed), forfeiting coins/shop.
Progression: Beat blinds to advance; end after round 8, prompt for endless mode (infinite scaling difficulty).
Shop: Buy charms; accessed post-blind (skipped if tag used).
Achievements/Unlocks: Track progress (e.g., hand plays, scores); unlock charms/bags.
Tutorial: Mostly complete; add sections for Prism packs (multi-hand bonuses?), Rune packs (enhancements?), and tags.

3. Functional Requirements
3.1 Core Gameplay Loop

Splash → Select bag (if unlocked) → Blinds Screen (view rounds/boss).
Game Screen: Roll/form hand → Score vs. blind.
Post-blind: Optional tag application (skip for buff) → Shop (if not skipped) → Next blind.
After round 8: End screen prompt for endless mode (continue with scaling blinds/charms).
Pause anytime; achievements tracked in background.

3.2 New Features: Tags

Mechanics: Applied in Blinds Screen; skip small/large blind for buff (e.g., +multiplier, extra charm slot). Instant tags activate immediately; delayed trigger on next boss/final round. Downside: No coins from skipped blind, no shop access.
Implementation: Add tag data in data.py (e.g., list of 20+ tags with effects, triggers). UI in Blinds Screen: Clickable tag options per blind.
Balancing: Random tag availability; costs or risks for powerful ones.

3.3 New Features: Game End and Endless Mode

End Conditions: After beating round 8 boss, display victory screen with score summary, achievements unlocked.
Endless Mode: Prompt "Continue to Endless Mode?" (yes/no). If yes, infinite rounds with escalating stakes (e.g., +10% difficulty per round, new random bosses). Track high scores.
Implementation: In statemachine.py, add 'end' state; transition from blinds/game after round 8. Save endless progress separately.

3.4 New Features: Achievements and Unlockables

System: Track stats (e.g., hands played, scores achieved) via savegame.py. Achievements like "Three of a Kind Master: Play 100 Three of a Kind" unlock charms/bags.
Unlockables: 54+ charms locked (half of 108); e.g., unlock via "Score >5k" or "Beat Stake 5". Bags unlocked similarly (e.g., "Complete 10 runs").
UI: Dedicated achievements screen (accessible from pause/splash); progress bars, notifications on unlock.

3.5 New Features: Special Final Boss Blinds

Mechanics: For round 8 boss: Unique effects (e.g., "Ultimate Glitch: Disable 2 charms + shuffle dice"). Multi-stage or combined effects from prior bosses.
Implementation: Add to data.py BOSS_EFFECTS; flag for final boss in game logic.
