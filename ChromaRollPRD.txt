ChromaRoll Product Requirements Document (PRD) - Updated

1. Introduction
1.1 Purpose
This updated Product Requirements Document (PRD) builds on the initial version, 
incorporating a deeper analysis of the GitHub repository. It now includes the 
previously omitted Challenges Screen, based on code structures in statemachine.py 
and screens.py (e.g., 'challenges' state and draw_challenges_screen function). 
The PRD details existing features, game structure, and screens, while outlining 
new additions you specified: "boons" for challenges (renamed and differentiated 
from Balatro's tags, with optional d20 roll for thematic risk/reward), game end 
conditions with endless mode, expanded charm count (50+ functioning, total 108 
planned), porting plan to Android and PC (Steam), achievement system with 
unlockables (e.g., half or more charms locked behind progression), bag unlock 
conditions, tutorial enhancements (explaining Prism packs, Rune packs, and 
boons), and special "boss challenges" for the final boss.
The repository analysis confirms a modular Pygame-based architecture with files 
for main loop (ChromaRoll.py), state management (statemachine.py), UI rendering 
(screens.py), data definitions (data.py), helpers (utils.py), constants 
(constants.py), and persistence (savegame.py). Assets are in /assets/ for 
images, audio, and fonts. Debug mode enables testing with infinite resources.

1.2 Scope
Current Scope: Core loop including dice rolling, hands, 50+ charms, pouches 
(bags), boss effects, progression through challenges/phases, shop, and basic 
UI/audio.
New Additions in Scope: Challenge boons (optional d20-rolled intensifiers that

endless mode option, achievement/unlock system (e.g., progression-based charm 
unlocks), bag unlock conditions, tutorial updates for Prism/Rune packs and 
boons, special final boss challenges.
Out-of-Scope: Multiplayer, advanced AI opponents, real-money purchases. Porting 
is planned but not yet implemented.
Target Platforms: Desktop (PC via Steam) and Mobile (Android). Initial 
development in Python; porting required.

1.3 Audience
Players: Casual to strategic gamers enjoying roguelike dice mechanics.
Developers: You and contributors; porting may involve external tools/frameworks.

1.4 Assumptions and Dependencies
Dependencies: Pygame; assets in /assets/.
Assumptions: Mouse/touch controls (adaptable for Android); local saves; no 
online features initially.

2. Game Overview
ChromaRoll combines Balatro-inspired progression with Yahtzee-style dice 
rolling. Players form hands to beat challenge targets, equip charms for bonuses, 
select starting bags, face boss effects, and shop between rounds. Progression 
through phases increases difficulty, with new boons allowing intensification of 
minor/major challenges for variable buffs (at the cost of higher risk and no 
standard rewards if failed). Game ends after round 8 with endless mode option. 
50+ charms are functional; total planned: 108, with many unlockable via 
achievements.

2.1 Key Mechanics
Dice and Hands: Roll 5 colored dice; hold/reroll/discards to form hands (e.g., 
Pair, Straight, Flush). Scores beat challenges. Players start with 25 dice 
total: 5 each of base colors (red, blue, green, purple, yellow). In each phase, 
players typically have 3 hands (chances to score), 3 discards (usable for the 
entire challenge, up to 5 dice per discard action), and 3 rolls per hand. Hand 
types: Pair, Two Pair, Three of a Kind, Four of a Kind, Five of a Kind, Small 
Straight (4 numbers in sequence), Large Straight (5 numbers in sequence), Full 
House (2 dice of one number and 3 of a second). Bonus scores based on colors: 
"Rainbow" bonus (all different colors, scaling with dice used in combo); "Mono" 
bonus (all same color, scaling with dice); bonuses for 2-color combos (e.g., 
full house with matching colors per number group). After reaching target score 
for a challenge, popup shows coins gained from hands remaining, discards 
remaining, interest (+1 coin per 10 held), and bonuses from charms/special 
dice.
Charms: 108 total (50+ implemented); effects like multipliers or modifiers. 
Half+ unlockable (e.g., "Play 100 Three of a Kind" or "Score >5k in one hand").
Bags (Pouches): Starting bonuses; unlockable via conditions (e.g., complete X 
phases, achieve Y scores). 8 pouch types: Red (+1 discard, 2 extra red dice); 
Blue (+1 hand per round, 1 extra blue die + 1 extra silver die); Yellow (+10 
extra starting coins, no extra colored dice); Green (+2 extra coins per 
remaining hand +1 extra coin per remaining discard); Black (1 extra charm slot 
but -1 hand per round +1 extra special die at random); Glass (higher chance for 
special dice boxes in shop +1 extra glass die); Erratic (white; completely 
randomizes the 25 dice with base colors); Plasma (TBD).
Boss Effects: 30+ modifiers; special variants for final boss (e.g., amplified 
effects, multi-phase challenges).
Challenges and Boons: Targets to beat; boons allow intensifying minor/major 
challenges for variable buffs (instant or delayed, via optional d20 roll), 
risking failure with heightened difficulty.
Progression: Beat challenges to advance; end after round 8, prompt for endless 
mode (infinite scaling difficulty). 8 phases total for main loop, with 3 
challenges per phase (minor, major, boss); endless continues after Phase 8.
Shop: Buy charms; accessed post-challenge (skipped if boon intensification leads 
to immediate progression or failure). In Shop Screen: Choice between 3 unique 
charms (not already held) in top row; second row for packs (Dice boxes: 
base/special colors; Prism packs: increase hand type modifiers; Rune packs: 
purchasable buffs/runes applied to dice). Buying Dice/Prism box opens new 
screen to choose 1-2 items. Buying Rune pack opens screen with 8 random dice 
below 3-5 runes; select dice for modifying runes (choice to skip pack).
Achievements/Unlocks: Track progress (e.g., hand plays, scores); unlock 
charms/bags.
Tutorial: Mostly complete; add sections for Prism packs (multi-hand bonuses?), 
Rune packs (enhancements?), and boons.

3. Functional Requirements
3.1 Core Gameplay Loop
Load Screen -> Splash Screen (New Game, Load Game, Quit) -> Pouch Selection 
Screen (8 bag types) -> Challenges Screen (option to roll d20 boon or pass for 
shop after beating challenge; shows highlight for current challenge 1/3, total 
scores needed per challenge, preview of boss on challenge 3) -> Game Screen 
(rolling on green casino table) -> Shop Screen (if pass d20) -> back to 
Challenges Screen.
Game Screen: Roll/form hand -> Score vs. challenge.
Post-challenge: Optional boon application (intensify with d20 roll for variable 
buff) -> Shop (if not skipped)
-> Next challenge.
After round 8: End screen prompt for endless mode (continue with scaling 
challenges/charms).
Pause anytime; achievements tracked in background.

3.2 New Features: Boons
Mechanics: Applied in Challenges Screen; intensify minor/major challenge for 
variable buff (e.g., +multiplier, extra coins/discards). Instant boons activate 
immediately; delayed trigger on next boss/final round. Downside: Heightened 
score target increases failure risk, no standard coins/shop access if 
intensified. Optional d20 roll (random.randint(1,20)) determines tiered outcome 
(5 fixed initially, 1 outcome per tier: 1-4 hard/high-reward [Prism Fracture: 
+50% target, disable hand type; success: refract to +2x buff + Prism pack], 5-8 
challenging [Hue Dimming: +25% target, -20% random color score; success: +2x 
multiplier +20 coins], 9-12 neutral [Roll Harmony: +8% target, stabilize 1 
reroll; success: +1.5x multiplier +1 discard], 13-16 favorable [Roll Flow: 
-12% target, +1 extra reroll + advantage on 1 die (spawn copy above for second 
chance roll); success: +2.5x multiplier + free full discard up to 5], 17-20 
crit success [Chroma Radiance: -25% target, +30% all colors score; success: 
+4x multiplier next 2 challenges +50 coins + achievement progress]; no 
permanent charm slots; variants per tier planned for medium-term). Optional 
color fusion modifies tiers (e.g., fused color targeted/buffed).
Implementation: Add boon data in data.py (e.g., list of 20+ boons with effects, 
triggers, d20 tiers). UI in Challenges Screen: Clickable boon options per 
challenge; animate d20 roll (use blank d20 PNG base with overlaid number via 
Pygame font blit).
Balancing: Random boon availability; costs or risks for powerful ones. Test d20 
in debug (force rolls).

3.3 New Features: Game End and Endless Mode
End Conditions: After beating round 8 boss, display victory screen with score 
summary, achievements unlocked.
Endless Mode: Prompt "Continue to Endless Mode?" (yes/no). If yes, infinite 
rounds with escalating phases (e.g., +10% difficulty per round, new random 
bosses). Track high scores.
Implementation: In statemachine.py, add 'end' state; transition from 
challenges/game after round 8. Save endless progress separately.

3.4 New Features: Achievements and Unlockables
System: Track stats (e.g., hands played, scores achieved) via savegame.py. 
Achievements like "Three of a Kind Master: Play 100 Three of a Kind" unlock 
charms/bags.
Unlockables: 54+ charms locked (half of 108); e.g., unlock via "Score >5k" or 
"Beat Phase 5". Bags unlocked similarly (e.g., "Complete 10 runs").
UI: Dedicated achievements screen (accessible from pause/splash before/after 
games); progress bars, notifications on unlock; hints for unlocking 
charms/other features.

3.5 New Features: Special Final Boss Challenges
Mechanics: For round 8 boss: Unique effects (e.g., "Ultimate Glitch: Disable 2 
charms + shuffle dice"). Multi-stage or combined effects from prior bosses.
Implementation: Add to data.py BOSS_EFFECTS; flag for final boss in game logic.

3.6 Data Structures (from data.py and Analysis)
Hand Types: Poker/Yahtzee-inspired with scores/multipliers.
Charms: 108 planned (50+ functional); effects categorized (e.g., score boosts, 
reroll aids).

Boss Effects: 30+; add special final variants.

Extend to include achievements, unlocks, endless mode scores.

animations.
