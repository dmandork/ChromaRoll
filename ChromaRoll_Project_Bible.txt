Game Overview

2.1 Key Mechanics
ChromaRoll is a roguelike dice-poker game inspired by Balatro and Yahtzee. Players roll 5 colored dice, hold/reroll/discard to form poker-style hands, and score against escalating blind targets. Charms provide powerful modifiers, bags give starting advantages, and boss effects add challenge. The D20 Boon System allows players to intensify challenges for high-risk/high-reward outcomes. The game runs for 8 rounds (phases) before offering endless mode.
2.2 D20 Boon System Overview
The D20 Boon System is an optional risk/reward mechanic accessed on the Challenges Screen. Players can choose to intensify a minor or major challenge (skipping the normal shop/coins) in exchange for rolling a d20 that determines one of 5 tiered outcomes. Color fusion (optional) modifies the outcome for additional strategy. Low rolls are punishing but offer strong comeback potential; high rolls are powerful buffs. All effects are temporary.
The 5 d20 Outcomes (exact as defined in RollOutcomesD20.txt):
1-4: Crit Fail – Prism Fracture

Base Effect: +50% score target; randomly disable one hand type this challenge only.
With Color Fusion: Disable ties to fused color (hands using fused color are exempt).
Success Reward: +2× multiplier on the disabled hand type for the next challenge + free Prism Pack in the next shop.

5-8: Challenging – Hue Dimming

Base Effect: +25% score target; one random color scores -20% this challenge.
With Color Fusion: Targets the fused color (-20%), but success brightens it (+30% next challenge).
Success Reward: +2× multiplier on the next hand +20 coins.

9-12: Neutral – Roll Harmony

Base Effect: +8% score target; one random die is locked (cannot be rerolled this round).
With Color Fusion: Lock applies to fused-color dice.
Success Reward: +1.5× multiplier for this entire challenge +1 extra discard.

13-16: Favorable – Roll Flow

Base Effect: -12% score target; +1 extra reroll this round + advantage on 1 chosen die (spawns a duplicate above it).
With Color Fusion: Advantage prioritizes fused-color die.
Success Reward: +2.5× multiplier this challenge + free full discard (reset all 5 dice).

17-20: Crit Success – Chroma Radiance

Base Effect: -25% score target; all colors score +30% this challenge.
With Color Fusion: Fused color explodes to +50% and acts as wildcard next hand.
Success Reward: +4× multiplier for the next 2 challenges +50 coins + achievement progress.

3.11 Charm Interaction Analysis (Potential Problem Areas Needing Testing)
After reviewing all 108 charms against the current code (ChromaRoll.py, game.py, scoring.py, d20_boon.py, debug.py), here are the highest-risk interactions that need focused testing:
High Priority (Test Immediately)

Mime Charm + Glass dice / Fragile Fortune: Mime retriggers held Glass dice → double break chance + double mult/penalty.
Mime Charm + Gold/Silver: Retriggers coin gains on held/not-held dice (can lead to massive coin spikes).
Dagger Charm: Sacrifice order depends on equipped list position. Dragging charms can unpredictably change which charm is sacrificed.
Hiker Hex + permanent bonuses (Ice Shard, Lucky Labyrinth, Square Sphere): Multiple permanent scaling effects may stack or conflict in scoring.
Turtle Token + Burglar Bag: Hands decay timing vs. +3 hands on blind start can lead to negative or incorrect hand counts.
Stencil Charm: Depends on exact equipped count and max_charms; empty slots must be calculated correctly after drags/sells.
Cloak of Cunning: One-time loss prevention destroys the charm and repeats the blind — must not trigger multiple times or on final boss.
Luchador Lens: Only disables non-final bosses; must not work on round 8 boss.
Buy Boon / Disadvantage Dice / Whirlwind Wild: Selection modes, coin costs, and shift limits must not leak between turns or blinds.
Rune Recycler + any mystic rune: Reuse flag must reset properly per shop/blind and not allow infinite reuse.

Medium Priority

Synergy Scroll + Mime: Retriggering enhancements on special colors while Mime is active.
UNO Draw 2 / UNO Skip: Per-blind flags must not carry over between blinds or runs.
Necromancer’s Needle + destroyed dice tracking: Revive logic must work with full_bag sync.
Sorcerer’s Surge: Random mult per turn — must reset correctly on new_turn.

Low Priority

Most color-specific charms (Greedy Gambler, Envy Echo, etc.) are straightforward but should be tested with rainbow/wild dice.
Permanent scaling charms (Ice Shard, Square Sphere, etc.) need long-run testing for balance.


File Structure & Detailed File Explanations

Root Folder (ChromaRollPython)

ChromaRoll.py (main entry point – ~127 KB)
This is the heart of the game. It defines the ChromaRollGame class that holds all global state and orchestrates the entire game.
Key methods and what they do:
init(): Initializes Pygame, loads all icons/sounds/fonts into caches, sets up audio, creates D20BoonSystem, loads charm icon paths, calls _init_defaults().
_init_defaults(): Resets all core variables (bag, full_bag, rolls, held, multipliers, flags, etc.) for a fresh game or reset.
new_turn(): Draws a new hand, resets holds/rerolls/discards, applies per-turn charm effects (Sorcerer’s Surge, Turtle Token, etc.), handles Roll Harmony lock.
roll_hand() / reroll(): Performs actual dice rolls with animation and boss effect handling.
score_and_new_turn(): Core scoring logic — calls evaluate_hand, accumulates coins/interest/runes/Luck’s Locket/Echo Ember, handles Tier 1 Prism Fracture reward, shows win popup or triggers game over/Cloak of Cunning.
advance_blind(): Moves to next blind/stake, refills bag, applies boss effects, resets D20 flags, handles Turtle/Burglar Bag.
generate_shop(): Creates shop charms and packs with weighted rarity, handles free Prism Pack from Tier 1.
apply_rune_effect(): Applies mystic runes to selected dice.
refresh_bag(): Syncs modifications from bag back to full_bag after rune changes.
toggle_hold(): Toggles hold on dice with special logic for advantage/Fate’s Favor.
run(): Main 60 FPS game loop (event handling → update → draw).

states/game.py (main gameplay state – 54 KB)
Handles everything that happens while actively playing a blind.
Key methods and what they do:
enter(): Called when entering the game screen — resets D20 flags, applies Tier 1 bonus, Turtle Token, Burglar Bag, Marble Mystic, forces fresh hand draw, resets advantage/Fates flags.
update(dt): Handles timers (break effects, temp messages), auto-rolls advantage die.
draw(): Calls draw_game_screen, overlays popups, draws buttons, advantage/Fates rects, tooltips, Buy Boon/Disadvantage arrows.
handle_event(event): Processes all mouse input: dice clicks (hold/discard), charm activations (Fate’s Favor, Buy Boon, Disadvantage Dice, Whirlwind Wild, UNO Draw 2, Luchador Lens), bag swap for Familiar’s Foresight, tray rune clicks, button clicks.
update_die_rects(): Recalculates precise clickable rectangles for hand dice, bag dice, advantage die, and Fate’s Favor die every frame.

states/debug.py (debug menu – 24 KB)
Provides in-game debug tools for rapid testing.
Key classes and what they do:
DebugMenuState: Main debug menu with buttons to access charm/prism/rune debug screens.
DebugCharmState: Scrollable list of all charms with search box; clicking adds any charm to equipped (bypasses normal limits for testing).
DebugPrismState: Allows boosting any hand type multiplier instantly.
DebugRuneSelectState: Lists all mystic runes; selecting one proceeds to dice selection.
DebugDiceSelectForRune: Lets you select dice for rune application in debug mode (bypasses normal limits).
TextBox: Reusable search/input box used in charm debug screen.
This file is extremely useful for isolating charm interactions and testing edge cases without playing full runs.

data.py (32 KB)
Pure data file containing CHARMS_POOL (all 108 charms), HAND_TYPES, BOSS_EFFECTS, POUCHES, DICE_DESCRIPTIONS, etc.
d20_boon.py (9 KB)
Full D20 Boon System logic: roll handling, tier outcomes, fusion, pending rewards.
scoring.py (35 KB)
The complete scoring engine: evaluate_hand function (hand detection, all charm processing, modifiers, dimmed/chroma logic, advantage die).
constants.py (9 KB)
All UI/layout constants, colors, sizes, THEME dictionary.
screens.py (115 KB)
All pure drawing functions (draw_game_screen, draw_shop_screen, draw_dice, draw_buttons, tooltips, popups, etc.).
utils.py (4 KB)
Helper functions (resource_path, tint_image, draw_rounded_element, wrap_text).
savegame.py (14 KB)
JSON save/load system for all game progress.

states/ subfolder
Contains one file per screen state (each inherits from base.py): game.py, shop.py, d20_roll.py, blinds.py, rune.py, pack_select.py, pause.py, splash.py, tutorial.py, end_prompt.py, game_over.py, debug.py, and supporting files like confirm_sell.py, dice_select.py, etc.
assets/
Contains all images, icons, fonts, and audio files.
